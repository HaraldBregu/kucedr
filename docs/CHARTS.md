# Charts in Chat

## Context

The agent can only answer in text, markdown tables or media. We want it to draw charts inline in the chat when the user asks for one or when the data reads better as a chart.

The renderer owns a few fixed chart types built on shadcn/ui's chart component, which uses Recharts. The agent only supplies data. It does this by calling a tool, so the input is checked against a zod schema and the chart is saved in history like any other tool call.

## How it works

1. The agent calls `create_chart({ type, title, data, xKey, series })`.
2. The tool's `execute` does no work in main and returns `{ ok: true }`.
3. The renderer sees a tool part with `type === 'create_chart'` and draws a `<ChartCard>` from `tool.input` instead of the generic tool activity card.

## Main process

### Tool: `src/main/agent/tools/chart/create.ts` (new)

It follows the pattern of `tools/health/get.ts` and uses the `tool()` factory from `tools/tool.ts`.

- `id: 'create_chart'`, `planSafe: true`, and a fitting category from `tools/category.ts`.
- `inputSchema` (zod):
  - `type`: `'bar' | 'line' | 'area' | 'pie'`
  - `title`: string
  - `description`: string, optional
  - `data`: array of records with string or number values, at most 200 rows
  - `xKey`: string, the category or x-axis field (the slice name for pie)
  - `series`: array of `{ key, label }`, 1 to 6 entries, which are the numeric fields to plot (pie uses the first entry)
- `execute`: returns `{ ok: true }`. The model already knows what it sent, so returning less keeps tokens down.
- Description: "Render a chart in the chat. Use when the user asks for a chart/graph/plot, or when comparing numbers across categories or time would be clearer visually. Provide real data only; never invent values."

### Registration

Add `createChartTool(config)` to the array in `builtinTools()` in `src/main/agent/runner/run_builtin_tools.ts`, next to `getHealthTool`.

### Instructions

Add one bullet to `## Core instructions` in `src/main/agent/system/system_add_base_prompt.ts`:

> When numeric data is better shown visually (trends, comparisons, shares), call `create_chart` instead of a markdown table; keep a one-line text summary.

The tool description does most of the work, so the prompt needs nothing more than that.

## Renderer

### shadcn chart component

Run `npx shadcn@latest add chart`. That creates `src/renderer/src/components/ui/chart.tsx` and adds `recharts` to `package.json`.

### `src/renderer/src/pages/home/components/ChartCard.tsx` (new)

It takes the chart input and switches on `type`:

| `type` | Recharts component |
|--------|--------------------|
| `bar`  | `BarChart`  |
| `line` | `LineChart` |
| `area` | `AreaChart` |
| `pie`  | `PieChart`  |

- All four sit inside `ChartContainer`, `ChartTooltip` and `ChartLegend`.
- Build `ChartConfig` from `series`, assigning colors `var(--chart-1)` … `var(--chart-5)`. These are the shadcn theme tokens, so light and dark mode already work.
- Render the title and description with shadcn `Card`.

### Wiring in `AssistantMessage.tsx`

Add one branch to the per-tool if-chain (next to `ask`, `select_screen_source` and `request_mcp_authorization`):

```tsx
if (tool.type === 'create_chart') return <ChartCard key={tool.toolCallId} tool={tool} />;
```

- Show a skeleton while `tool.state` is `input-streaming`.
- Fall back to `ToolActivityGroup` on `output-error`.

## Skipped

- **Scatter, radar and composed charts.** Add them when someone asks for them.
- **Chart export or download.** Add it if users ask for it.
- **A markdown `chart` code-fence alternative.** It would stream with the text and skip the tool round trip, but it gives up schema validation. Switch to it only if the tool feels slow.

## Verification

1. Run `npm run dev` and ask "show monthly sales Jan–Jun as a bar chart: 10,20,15,30,25,40". A bar chart should render inline.
2. Ask for a line, an area and a pie chart. Each should render, and the colors should be correct in both light and dark themes.
3. Reload the conversation. The chart should still render from history.
4. Ask a plain question. No chart should appear.
5. Run `npm run typecheck` and lint.
