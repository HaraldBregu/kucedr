# What Kucedr can deliver today

On 25 November 2026, Kucedr could open a research brief in its desktop editor and export it in three formats. In a hands-on check, an exported brief referred to a source file that stayed on the analyst’s machine. A colleague receiving the export would need that file separately. Closing this gap is the most direct way to test the [proposed company briefing business](RESEARCH.md).

The source audit uses commit `61a6618104` as its baseline. The desktop check used the existing Electron build from earlier that day. Concurrent work added app-lock state and backup encryption code during the audit. Their complete setup, lock, recovery and restore flows were outside the verified build. Assess those changes on a dated release before making confidentiality promises. ## Which existing features earn their place

**Use the browser, document retrieval, Workspace editor and plugin skills in the first demonstration.** A firm can supply its own short report template and the analyst can use familiar Markdown and PDF outputs. If its client requires editable Word with tracked revisions, establish that at intake. The bundled DOCX skill and Workspace’s three export menu items provide different delivery paths. Production fidelity to a client’s Word template needs a separate check. [Workspace actions](../../src/renderer/src/pages/workspace/Actions.tsx) · [Bundled skills](../../resources/plugins/bootstrap/skills)

**Keep model choice and permissions visible when information leaves the machine.** Direct browser tabs share a persistent browser profile by default. The active workspace resolves to one location. The retrieval system checks consent for sending document or query text to the embedding recipient, with separate consent for a remote vector mirror. An analyst selecting a local chat provider still needs to understand their search and embedding choices. A different chat or folder alone cannot isolate client sessions, retrieval and sign-ins. [Browser profiles](../../src/main/agent/tools/web/browser/create.ts) · [Workspace location](../../src/main/shared/agent_location.ts) · [Retrieval consent](../../src/main/agent/knowledge/rag/consent.ts)

**Treat monitoring, backup and integrations as separate purchases to investigate.** The local scheduler can run a recurring task with configured capabilities while the app runs. Backup uses user-configured storage. MCP connectors can extend the user’s sources. Each introduces a dependency the first public-source trial can avoid. Ask for the last occasion a firm lost a case, missed a change or had to re-enter data before putting any of these ahead of review. Installer trust also deserves its own check on a client machine: the inspected packaging config disables notarisation and does not require code signing. [Task scheduling](../../src/main/tasks/tasks_create_task_job.ts) · [Cloud and backup](../CLOUD.md) · [MCP](../../src/main/mcp) · [Packaging configuration](../../electron-builder.json)

Voice, document co-authoring, charts and spreadsheets may help deliver individual assignments. Image generation, games, inbox triage and the coding interface have separate audiences. The pilot should open on the pending client question and its sources. Existing plugins make it possible to keep those other capabilities available without asking a reviewer to learn them. ## Order of work if firms commit to the pilot

1. **Demonstrate the handoff on public material.** Build one versioned source record and link one editable finding to a precise passage. Export the brief alongside the permitted source material. Pass when a second person can correct an overstated claim in a fresh profile after the original page changes.
2. **Make the output fit a firm’s actual review.** Import one redacted template. Carry the analyst’s attribution, uncertainties and selected sources through edits and export. Pass when the reviewer can distinguish a company assertion from independent support and the analyst can deliver the agreed format without manual reconstruction.
3. **Prove client separation before using confidential material.** Exercise two cases with similar names and distinct documents, search history and browser sessions. Check retrieval after switching cases and restarting. Check the export contains only the intended case and that the analyst can account for the recipients of its content.
4. **Follow observed repeat use.** Use the paid-pilot thresholds in the commercial research to decide whether the next investment is unattended monitoring, team handoff, a specific registry integration or managed storage. A successful technology demonstration still leaves that purchase decision open. [Pilot design and economics](RESEARCH.md#paid-pilot-and-decision-criteria)
